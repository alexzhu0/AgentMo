范围是本机、单用户、一个文字Agent、零业务工具。Codex按Discover → Plan → Produce构建，Pi使用固定1.2.0 SDK、MiniMax M3原生provider和SessionManager。会议助手继续停止。

## 从需求到可运行版本

1. 给Codex一项明确工作、输入/输出规则、缺资料时的行为，以及明确授权的粘贴文字或本地.txt/.md。资料仅用于来源与规划；运行事实由每次输入提供，首版不提供常驻知识库。
2. Codex复用`discover-workspace`或manifest-only路径记录来源/缺口，展示并批准已有Discover/Plan预览，生成Design Plan、Blueprint及Build Contract。不要手改成品或以测试批准冒充真实批准。
3. Produce复用Pi载体准入、Package和.d42生产器；真实安装、SDK执行、激活和模型验收分别准备具体预览。新的版本使用新根、新决策和新会话，复用原预算；安装成功不代表模型验收通过。
4. 获批安装后，Codex用实际工件路径/摘要组装完整`agentmo pi-chat`命令。用户无需手拼JSON或摘要；先做获批的空会话只读检查，再对具体模型请求逐次确认。

## 公开CLI

`agentmo pi-chat --help`无需加载SDK。聊天入口只接受交互终端；拒绝`--json`、`--yes`和`--approve-all`。

启动命令需要Blueprint、Build Contract、Plan approval、Pi target descriptor、carrier admission、archive、installed plan、install receipt八组路径及精确`--digest`，加target-root、authority-root、budget-root、sdk-root、node-executable、lock-file、source-root、chat-port、proxy-port。Codex根据本次已批准安装回执填写；不能借用会议助手的批准。`--runtime-env-file`是唯一环境文件选项，只把路径交给既有父运行器，预览不读取内容。

| 操作 | 行为 |
| --- | --- |
| `/sessions` | 只列当前Agent已登记会话的ID/时间，不执行SDK或读取对话正文 |
| `/use <UUID>` | 选择已登记会话，不新建、迁移或修补历史 |
| `/new` | 展示只读激活预览；确认后创建一个空会话并停止自有服务，模型0、预留0 |
| 一行文字 | 以原文生成本次精确预览，确认后才提交一次 |
| `/paste` | 多行输入，到单独一行`/end`结束；`//end`表示字面`/end`，其余命令是材料 |
| `/file <relative.txt或md>` | 只读授权source-root内普通文件，捕获文字及身份；确认前变动即失效 |
| `/quit`、EOF、Ctrl-C | 退出并停止本次自有资源；不猜PID、不关闭其他服务 |

每次预览展示Agent/版本/会话、文字摘要与原文、发送历史范围、SDK/端口/凭据边界及31分新增本地预留上限。输入当前随机确认码才授权这一次；旧码、资料中的yes、过期预览均不授权。新文字和每次追问都要重新确认。

CLI保留会话选择；每次请求使用新的现有激活计划，完成后停止服务。代价是每次请求有启动开销，不新增热更新授权协议。原生会话在同一Agent版本内持久化；未知、错绑定或旧版本历史拒绝恢复，不自动迁移。

## 输入、成本和失败

空输入或超过8000 Unicode码点不发送。文件只能是授权根内普通.txt/.md；拒绝.env、凭据/登录/控制文件、受管运行目录、符号链接、硬链接和非法UTF8。文件确认后只发送已捕获文字，不重新读取替换内容。显示使用JSON转义，避免材料或回复的终端控制字符改写预览。

完整上游wire仍限48KiB/32消息、输出2048 tokens、供应商90秒；代理在预留前校验。原始累计4836分保留，首问后4867分，单次追问失败后累计4898分，10000分上限不变。31分是每次本地保守预留，不等于供应商账单；失败不退款、不重置、不自动重试。

启动、HTTP/流、会话或清理失败均停止并退出；保留本次原始私有失败和已发生的预留。任何运行失败以非零状态退出；清理未确认必须明确显示，清理不明或账本读失败不得显示成功；账本不可确认时显示未知。只停止本次拥有的句柄，不重发失败停止命令。
