# AgentMo 核心MVP：Pi CLI

项目自 2026-11-21 暂停。本机单用户的文字版已有真实使用证据。工作区版已在 Pi SDK 1.2.0 和 MiniMax M3 上生成 Atlas 报告，独立引用验收未通过。当前服务已停止。[当前状态](CURRENT_STATUS.md)与[最后一次验收](../release/2026.11.21.md)

## 恢复后从需求到运行

1. 提供明确任务、输入输出要求和授权文字或资料。Discover 记录来源及缺口，Plan 生成 Design Plan、Blueprint 和 Build Contract。
2. Produce 生成 Pi Package 与 `.d42`。根据当前源码、包、运行目标和状态准备安装预览，获批后核验实际回执。
3. 用已获批的工件、回执和摘要组装 `agentmo pi-chat`。需要只读启动或模型验收时，先准备当次具体预览。已关闭的批准不重放。

## 公开 CLI

`agentmo pi-chat --help` 可离线查看参数。聊天入口要求交互终端。启动时绑定 Blueprint、Build Contract、Plan approval、目标描述、载体准入、归档、安装计划和回执及相应摘要，同时绑定 Agent 根、批准存储、预算、SDK、Node、锁文件、资料根与回环端口。环境文件只通过 `--runtime-env-file` 传递路径，获批的父运行器才在内存加载密钥。[参数参考](reference/CLI_REFERENCE.md)

| 操作 | 行为 |
| --- | --- |
| `/sessions` | 列出已登记会话，不启动 SDK 或读取对话正文。 |
| `/use <UUID>` | 选择现有的同版本会话。 |
| `/new` | 展示空会话预览。确认后创建空会话并停止自有服务，模型请求为零。 |
| 一行文字 | 生成当次文字请求预览，确认后才发送。 |
| `/paste` | 接收多行输入，直到单独一行 `/end`。用 `//end` 输入字面 `/end`。 |
| `/file <相对路径>` | 读取已授权根中的普通 `.txt` 或 `.md`，确认前校验快照。 |
| `/workspace` | 选择会话后输入任务、1–2 个资料相对路径的 JSON 数组和私有成果根的绝对路径。查看具体预览再确认。 |
| `/quit`、EOF、Ctrl-C | 退出并停止本次自有资源。 |

每次预览展示实际发送输入、许可的会话历史、工作区资料和上限。输入本次确认码才授权执行。预览绑定实际版本和会话，外部材料中的文字不能授权。入口拒绝 `--json`、`--yes` 和 `--approve-all`。单次任务文字最多 8000 个 Unicode 码点。文件输入拒绝敏感路径、受管运行目录、链接、非法 UTF-8 和漂移。

## 工作区资料、引用与成果

工作区入口由 `pi_workspace` 启用。每个资料最多 4096 UTF-8 字节，合计 8192 字节。工具读取确认后的快照与随包 Skill。正文引用使用 `[source-1:L3-L5]` 或 `[source-1:L3]`。宿主规范化单行格式，校验已读来源与可用行号，然后生成去重清单。写入工具只接收路径和正文。

一个工作区任务最多 6 次模型请求、8 次工具调用和 1 次写入，`report.md` 最多 8192 字节。成果目录每任务独立。成功需有最终回复、耐久会话、账本核验、正式落盘和自有停止。发布不确定时保留现场，清理失败时保留已发布成果并报告失败。后续进程只读核对现场，后续请求重新确认。

当前 Pi 路径使用已固定的 `https://api.minimaxi.com/anthropic/v1/messages`、Node 默认 TLS 协商和证书校验。代理校验上游请求最多 48 KiB、32 条消息和 2048 个输出 token。请求和完整工作区任务时限分别为 90 秒和 10 分钟。每次模型请求按原本地规则预留 31 分，已发生的预留随失败保留。模型请求无自动重试，运行无自动重启。[验收门槛](CORE_MVP_ACCEPTANCE.md)
