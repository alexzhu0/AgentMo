## 离线检查

离线用例使用合成 SDK、合成资料和独立账本。需要回环监听的合成用例应记录执行环境。可从仓库根运行相关用例。

```bash
verification_tmp="$(mktemp -d)"
TMPDIR="$verification_tmp" node --test \
  test/pi-*.test.js test/core-mvp.test.js test/course-wiki-budget.test.js \
  test/artifact-subjects.test.js test/artifact-surface-coverage.test.js \
  test/command-docs.test.js
```

| 门槛 | 证据要求 |
| --- | --- |
| 不同需求生成不同 Agent | 两个合成需求分别经过工件生成与归档读取，产生不同职责。 |
| 包与 Builder 兼容 | 清单及归档与正确定义一致，额外成员和内容漂移被拒绝。 |
| 请求与会话 | 逐次确认、绑定会话、限制请求数及预算，失败保存原终态。 |
| 工作区 | 覆盖确认、工具IPC、预算、原生历史、规范化报告及清单、落盘和只读恢复。未读来源、无效行号或越界写入被拒绝。 |
| 冷包入口 | 在无依赖和运行状态的解压环境内，公开 help 及缺参拒绝正常工作。 |

## 真实内容验收

安装、空会话、实际请求和自有停止分别记录。报告须同时核对规范化文件摘要、正文与清单对应、来源和实际物理行号。独立评审逐项确认引用能支持正文事实，并核对信息缺口。只有执行和内容均通过才交付验收成果。
