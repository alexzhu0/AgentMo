# 2026.07.28 — Phase 3 bounded discovery, exact Plan authority, and Package build contract

## Status

AgentMo now has a public `discover-live` command that exact-admits a discovery manifest, retrieves only explicitly allowlisted HTTPS sources under bounded policy, and publishes provenance-bearing Stage 1 artifacts as one preflighted set. Web, GitHub REST, arXiv metadata, and approved local documents share a common evidence vocabulary plus deterministic mechanical observations. Plan entry requires both an explicit exact-digest local approval artifact and the current predecessor-bound decision-ledger head. Plan can now end in a strict, source-grounded `agentmo.build-contract.v1` plus a separate exact-byte `agentmo.plan-approval.v1`. Wiki persistence, a runnable Agent Package, installation, and OpenClaw execution remain later work.

## Security and evidence semantics

- Only exact allowlisted HTTPS URLs are accepted; URL credentials, unsafe redirects, private/reserved connection results, unsupported status/content type, oversized bodies, invalid UTF-8, sensitive text, and expired deadlines fail closed.
- DNS results are checked and the selected public address is pinned into the HTTPS request.
- Response bytes are bounded and hashed before any text derivation.
- Raw response bodies and unrestricted headers are not persisted.
- Successful retrieval remains `bounded-mechanism-only`; semantic quality, domain quality, runtime readiness, and production readiness remain false.
- The requested output root remains absent when candidate preflight or publication fails.
