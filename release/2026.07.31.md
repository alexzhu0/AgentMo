## Platform and execution boundary

- Linux is the only implemented official-config execution route because it has
  the retained `/proc/self/fd` transport used by this contract.
- Darwin returns `platform-fd-config-transport-unavailable`. Native Darwin
  no-replace publication support does not imply config execution or four-
  lifecycle macOS completion.
- The process-group mechanism is bounded supervision, not an OS sandbox. A
  same-uid descendant can attempt a `setsid` escape and remains a residual risk.
- Credential routes are grammar/proposal artifacts only. There is no Phase 4
  credential spawn, presence proof, MCP route, plugin activation, agent/schedule
  execution, or credential-state certification.
