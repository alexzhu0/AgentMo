# 2026.07.06 — AgentMo MVP birth-loop

## 背景

到 2026-07-06，AgentMo 已经有：

- blueprint validation/report；
- deterministic plan/scaffold/build-state；
- OpenClaw target；
- runtime plan/run/replay/eval；
- DeepSeek/OpenClaw live POC。

但这些还不是完整 AgentMother MVP。缺口是：

```text
找到做什么
-> 结合用户需求规划
-> 生成 agent blueprint / handoff
-> scaffold/run/eval
-> fail-closed birth gate
```

因此本阶段目标是把 AgentMo 从 runtime/evidence POC 推进成第一个可复用的 agent birth-loop。

## 关键修复链

Ultragoal 记录显示初版实现后经历了严格 code-review 修复：

- G001：fail-closed runtime evidence 和 birth-report 语义。
- G002：runtime timeout、OpenClaw live plumbing、replay env/redaction。
- G003：验证与 review。
- G004：修复 final code-review blockers。
- G005：修复第二轮 final blockers。

最终修复内容包括：

- run-state/birth-report 不再信任 evidence 自我声明，而是从 execution/evidence 共同推导 raw-output eligibility。
- live provider run 必须有 runtime env readiness。
- generic JSON 不能伪装 structured OpenClaw output。
- fallback-only / transport-only JSON 仍视为 raw-output evidence。
- timeout cleanup 必须有正向 process-group verification。
- docs 中预先写死“review approved”的语义被移除或降级。

## 架构决策

采用：

- birth-report 在 generator 扩张前先落地。
- declared evidence 与 live-success evidence 严格分层。
- support-triage 作为非 Win9 fixture，证明不是 Win9-only。
- AgentMo 生成 Codex/OMX handoff，不在 MVP 内直接调用 Codex 执行。
- deterministic Node CLI，暂不引入外部依赖。

拒绝：

- UI-first。
- LLM-first automatic generator。
- handoff-only。
- 用 declared/non-live evidence 伪装 runtime birth。
- 用 live smoke 伪装 domain certification。

## 非认证边界

本阶段可以说明：

- AgentMo 已经具备第一个 CLI-first AgentMother birth-loop。
- support-triage declared path 可走通。
- birth-report 能 fail-closed，并且不会把 declared evidence 提升为 runtime promotion。

不能说明：

- OpenClaw live-success promotion 已经完成。
- support-triage 或 Win9 已经完成领域质量认证。
- AgentMo 已经可以无人审查地产生生产 agent。

## 后续风险

- 当前 MVP 工作树尚未提交，commit 时必须只提交 AgentMo 文件，不能混入 `/pi` 的 Win9 harness 改动。
- declared-ready 不是 promotion-ready；runtime promotion 仍要求 isolated live smoke + `birth-report --expect-status success`。
- generated blueprint 是起点，仍需领域 review。
- 未来如果加入 LLM drafting，必须保留 deterministic fallback 和 birth gate。
