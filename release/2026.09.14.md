# Course Wiki OpenClaw：隔离文档知识库 POC（未完成验收）

## 背景与范围

为教学材料汇报演示增加独立 Course Wiki POC，而非继续扩展旧录音 POC 或
修改 AgentMo Discover → Plan → Produce 的授权语义。工作位于
`.worktrees/course-wiki`，分支 `codex/course-wiki`，基线
`b95dc43839845ad8304e40768787e946d0e4657b`。未 commit、push、发布或安装依赖。

支持 DOCX、Markdown、UTF-8 TXT；10 文件/批、2 MiB/文件、正文合计
100,000 Unicode code points。保存原始文件、来源和许可证，规范化正文用于
OpenClaw 原生 Wiki ingest/search/get/compile/lint。单页本机 UI 展示 Wiki、
提问与逐行原文引用；无独立向量库、模型 SDK 或框架依赖。

## 实现入口

- `src/course-wiki-documents.js`：有界文档转换、正文与来源映射、精确引用验证。
- `src/course-wiki-openclaw.js`：隔离原生 agent、Wiki 与模型回合。
- `src/course-wiki-budget.js`：固定模型/上游、持久调用预留与响应验证。
- `src/course-wiki-server.js`、`scripts/course-wiki-poc.mjs`：本机 HTTP 边界。
- `docs/poc/course-wiki/`：静态页面、运行说明、公开教材及来源清单。
- `docs/superpowers/specs/2026-09-14-course-wiki-openclaw-design.md` 与对应 plan。
- 本地未提交协调记录 `.superpowers/sdd/2026-09-14-course-wiki-openclaw/`。

## 安全与费用边界

用户批准公开教材首次测试上限 5 元；固定同一 root，最多 16 次请求，每次
调用前持久预留 0.31 元，共 4.96 元。失败也消费预留次数，无自动重试、退款、
重置或换 root 续额。这是保守预算预留，不是供应商账单实付金额。

用户接受 legacy `deepseek-v4-flash` 请求由当前 V4.1 Flash 服务；已观察实际
返回 `deepseek-flash`。请求模型、固定 HTTPS 上游、关闭 thinking、48 KiB
输入和 2,048 输出 token 上限不变。1 MiB 响应线格式上限仅容纳逐 token SSE
封装，不增加 token 或费用权限。官方兼容说明见
[DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/)。

密钥仅由 Node value-blind 加载并在转发进程内使用；不读取或记录 `.env`
内容，不传真实密钥至 OpenClaw 子进程、浏览器、配置或证据。隔离状态不影响
默认 OpenClaw profile。原始 provider payload / transcript 不作为证据保存。

## 非认证边界与剩余工作

Wiki 生成与持久化已证明机制可运行；主题摘要的部分论断超出其单条引用的
支持范围，因此领域质量仍为 PARTIAL。资料外拒答通过，但正向引用问答未
通过，5 道固定问题未完成；原始 16 次预算不足以继续完整问答，不得静默加额。
首次测试结束时提出小幅协议调整：让模型选择来源/行号，由程序确定性摘取
对应原文，而不让模型逐字抄写引用。用户于 2026-09-15 批准离线实现，后续
状态见 [`2026.09.15.md`](./2026.09.15.md)。本记录仍是旧协议下的真实测试
结果，不将离线修复追认成真实问答通过。新真实复测预算需另行授权。
