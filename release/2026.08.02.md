## Remediations

| Finding | Current mechanism |
| --- | --- |
| Replaceable canonical ledger identity | `agentmo.openclaw-authority-root-binding.v1` binds the exact target descriptor, target-root identity, authority-root inode, and derived authority id. Plans, approvals, receipts, post-effect evidence, and fresh re-admission carry that binding. Missing, renamed, or recreated roots fail closed; ledger open no longer creates directories. |
| Candidate pathname deletion race | Official config execution preserves its named private candidate. Path and retained-FD identities are checked before and after execution; replacement yields `AGENTMO_OPENCLAW_CONFIG_CANDIDATE_NAME_DRIFT`. No pathname unlink is used. |
| `setsid` descendant escape and pidfd capacity/admission | Linux uses the repository-owned native subreaper/pidfd supervisor, recycles terminal slots, and installs an inherited seccomp group lock that denies `setsid`/`setpgid` before `exec`. `/proc` enumeration plus the original process group retain a kill path across capacity or pidfd-admission failure. Non-Linux rejects before spawn. |

Re-audit 2 also found stale pre-final counts and a superseded `setsid` limitation
in maintained contracts. README, runbook, runtime notes, and Stage Contracts now
describe the current bounded mechanism and its still-mandatory Linux runtime
gate.

Re-audit 3 found three further Linux containment gaps: the target could signal
or stop its same-UID supervisor; direct pidfd/clock bootstrap failure could
return after killing only the direct PID; and x86_64 x32 syscall numbers bypassed
the native seccomp comparisons. Current source now:

- makes the supervisor non-dumpable and denies outbound signal syscalls,
  `pidfd_send_signal`, and `ptrace` in the inherited filter;
- uses a bidirectional pre-exec handshake, so target bytes cannot execute until
  direct pidfd and clock admission succeed; and
- rejects x32 syscall numbers on x86_64 before native syscall matching.

Six Linux-only supervisor tests now cover slot recycling, simultaneous capacity,
post-direct pidfd failure, supervisor kill denial, direct pidfd bootstrap
failure, and clock bootstrap failure. They are skipped on this Darwin host and
are not recorded as passed runtime evidence.

The new public package members are:

- `src/openclaw-authority-root-binding.js`
- `src/openclaw-process-supervisor.js`
- `native/openclaw-process-supervisor.c`

Prior Phase 4 install plans, approvals, and receipts do not bind this new root
authority. They must be regenerated and explicitly reapproved; Phase 3
discovery/build/target authority is not promoted or rewritten by this change.
