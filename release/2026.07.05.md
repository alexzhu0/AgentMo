```text
AgentMo blueprint
-> OpenClaw target/runtime plan
-> DeepSeek flash live run
-> run-state
-> run-report / run-eval / status
```

## 架构决策

采用：

- local-first DeepSeek/OpenClaw live smoke。
- optional gateway helper。
- `.env` 只作为本地 operator credential source，不进入 durable evidence。
- runtime env 记录 basename、allowed keys、present/missing keys、`valuesPersisted:false`。
- `transport=local` 必须映射 OpenClaw `--local`。
- `model` 必须映射 OpenClaw `--model`。
- replay 也必须保持 local/model/thinking fidelity。
- gateway fallback 必须记录为 `embedded-fallback` 或 unknown/failure，不能假装 gateway 成功。

拒绝：

- gateway-first 作为默认路径：移动件太多，secret/state 风险更高。
- script-only：不能修复 command descriptor 和 runtime identity 不一致的问题。
- 广义多 runtime adapter：对当时阶段过早。

## 安全边界

必须成立：

- 不打印 `.env` 值。
- 不持久化 API key、gateway token、proxy value。
- helper 默认清理 credential-bearing OpenClaw state。
- `--keep-state` 只能作为显式调试开关，且路径视为 credential-bearing。
- mandatory tests 不依赖 live provider。

## 非认证边界

本阶段可以说明：

- AgentMo -> OpenClaw -> DeepSeek flash 的 mechanism path 可行。
- AgentMo 有足够理由把 live-smoke path 产品化为安全 CLI/runbook 能力。

不能说明：

- Win9 在 OpenClaw 上完成领域 eval。
- OpenClaw runtime 已经替代 Pi runtime。
- DeepSeek flash 是所有 future agents 的默认最佳模型。

## 后续风险

- live path 依赖本机网络、provider credential、OpenClaw checkout 状态。
- gateway/local fallback 需要持续在 run-state 中保留真实 transport，而不是记录 operator 希望的 transport。
- secret redaction 需要持续测试 JSON field、Bearer token、explicit loaded secret values、stdout/stderr summary。
