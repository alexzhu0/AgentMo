# 2026.08.05 — Isolated OpenClaw information-agent POC lane

## Status

Adds a deliberately small local POC lane alongside the governed
Discover -> Plan -> Produce path. It creates an OpenClaw workspace from an
externally curated seed and can invoke one isolated, local DeepSeek-backed
turn after explicit operator command.

The same POC lane now has a bounded Stage 1 Research DB for the approved
white-collar discovery experiment: knowledge/document work,
meetings/collaboration, and data analysis/decision-making.

## Surface

- `agentmo poc build` now emits `agentmo.poc-workspace.v2`: seven OpenClaw
  workspace documents, seven bounded local Skills, a local Wiki, source/entity
  indexes, three cron proposals, and local Wiki/cron helper scripts. It retains
  one first record per canonical HTTPS URL with source URL, published time,
  collection time, source type, and trust tier.
- `agentmo poc check` reconstructs and verifies the complete static workspace
  closure from the canonical Wiki; missing or altered generated content fails
  closed.
- `agentmo poc run` uses a named OpenClaw profile whose HOME is inside the POC
  workspace, reads only the value-blind `--runtime-env-file` carrier, records
  an environment-variable reference (never a key value), trusts and installs
  the pinned official DeepSeek provider only in that profile, creates the
  isolated agent, and invokes one local turn.
- Runtime output retains only OpenClaw's text payload. Provider/session/tool
  metadata is not surfaced as the POC reply.
- OpenClaw JSON envelopes may be captured up to 256 KB so their metadata does
  not truncate the envelope before parsing; the redacted public reply remains
  limited to 16 KB. Non-JSON and missing-payload responses fail closed with
  value-blind diagnostics only.
- `agentmo poc build` now emits `agentmo.poc-workspace.v3`. Its immutable
  surface includes AI HOT intake, white-collar need signal, device/software
  watch, Research DB, daily-brief, and review-only skill-scout guidance; an
  AI HOT reference notice; and dynamic `research/` DB/state roots. Static
  workspace members remain exact-verified, while valid dynamic Research DB
  updates remain independently validated.
- `agentmo poc collect <workspace> --sources <registry>` requests only exact
  registered HTTPS source origins/paths, rejects unsafe final destinations and
  secret-shaped/oversize bodies, preserves only bounded metadata, handles a
  same-source ETag 304, and deduplicates by canonical URL then content digest.
  It does not use browser automation, generic search, delivery, or a schedule.
- `agentmo poc brief <workspace> --date YYYY-MM-DD` creates a local
  Asia/Shanghai daily evidence projection. Community signals stay labelled as
  community signals; generated hypotheses cite retained record IDs and carry
  low confidence when they lack primary/first-party evidence; empty scenarios
  become explicit evidence gaps.
- `agentmo poc schedule-preview <workspace>` returns only the declared
  `0 8 * * *` / `Asia/Shanghai` proposal with `executionAuthority: none`.
  There is no scheduler activation surface in this change.
- The main test lane now acquires one workspace-scoped temporary lock before
  spawning `node --test`. A concurrent `npm run check` fails immediately with
  `AGENTMO_CHECK_ALREADY_RUNNING` instead of competing with long Builder
  fault-injection suites and producing timing false negatives.

## Boundaries

- No AgentMo live collector, DNS/proxy workaround, schedule execution, delivery,
  browser, default OpenClaw profile, or user configuration mutation is
  included. The isolated profile's plugin and provider-reference changes
  require explicit operator command.
- Runtime replies are bounded and redact runtime-env secret values before CLI
  output; no credential values or raw source pages are persisted.
- Cron files are explicitly `proposal-only` with `executionAuthority: none`.
  Their helper supports validation and dry-run rendering only; it cannot
  register or start a scheduler.
- This is POC mechanism evidence only. A successful local turn does not
  certify source freshness, domain quality, production readiness, or the
  broader OpenClaw package lifecycle.
- The AI HOT upstream Skill and `last30days-skill` are never installed or
  executed. AI HOT is referenced through a closed API adapter; the latter is a
  `review-required` candidate only.

## Verification

- Focused POC and exact I/O inventory tests cover seed admission, workspace
  closure, indexes, inert cron proposals, isolated profile commands, secret redaction, bounded diagnostics,
  idempotent plugin/agent reuse, empty-reply rejection, and text-only result
  extraction.
- The first isolated `deepseek/deepseek-v4-flash` turn returned a Wiki-bound
  evidence answer. It did not claim an unsupported current paper, company
  update, or expert view.
- A subsequent v2 real run confirmed the envelope compatibility boundary: the
  local Wiki contained no item published on the run date, and the agent
  explicitly refused to invent one. No delivery or schedule was executed.
- Focused contract, collection, deduplication/index, workspace integrity,
  brief, CLI, and exact I/O inventory tests pass. The aggregate `npm run
  check` remains subject to the repository's separate native filesystem gate
  on macOS and does not certify live collection, scheduling, domain quality,
  or production readiness.
- Clean isolated replays of the two failures observed under three concurrent
  aggregate runs passed: the 86-member projection completed in 37.97 seconds
  against a 90-second bound, and retained-path substitution rejection passed
  in 10.03 seconds. This identifies concurrent aggregate runs as the failure
  source; it is not live-collection or domain evidence.

## Remaining gate

This is an intentionally narrow POC lane. A controlled host-network live
collection, a second idempotence collection, restart/query evidence, and an
exact scheduler activation approval remain separate work. Linux native CI also
remains a separate portability gate, not a blocker for macOS POC validation.
