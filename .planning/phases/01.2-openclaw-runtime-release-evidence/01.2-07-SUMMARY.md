## Decisions Made

- Caller normalization remains a dependency-free test contract, not a general-purpose shell parser. Supported syntax is deliberately bounded; unsupported or ambiguous OpenClaw-shaped execution fails verification.
- Generated owner discovery and maintained Markdown discovery both parse all candidate shell commands. A new wrapper cannot disappear merely because it is not line-leading bare `openclaw`.
- The canonical runtime range remains owned by `src/runtime-compatibility.js`; shell/docs only invoke the canonical CLI preflight and do not copy range arithmetic.
- Portable recovery text continues to forbid sibling project access by default. Replacing host paths does not broaden scope or authorize reading an OpenClaw checkout.
