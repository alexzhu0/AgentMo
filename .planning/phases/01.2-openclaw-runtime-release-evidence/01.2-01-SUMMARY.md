## Accomplishments

- 固定 AgentMo core `>=20` 与 OpenClaw target `>=22.19.0 <23 || >=23.11.0` 两份独立契约，并以严格 numeric triplet 解析精确封闭 22/23 断裂边界。
- 新增零参数生产断言：任何额外参数先以稳定有界错误拒绝，随后只从 `process.versions.node` 取得当前进程证据；纯谓词不是授权 seam。
- 新增 `agentmo runtime-check --target openclaw [--json]`，human/JSON 只输出 component、target、observed version、range、supported 与 evidence class 六项字段。
- 保持 `runtime-check` 为 zero-subject non-artifact command；既有 durable subject registry、输出 sink、错误 envelope 与 persistability gate 未被绕过。
