## Scope anchor

Phase 01.2 should add one small runtime policy and apply it at existing mutation seams; it should not redesign runtime planning, artifact admission, persistence, or the three-stage `Discover -> Plan -> Produce` mechanism.

Locked behavior:

- AgentMo core remains Node.js `>=20`.
- OpenClaw target mutation is allowed only for `>=22.19.0 <23 || >=23.11.0`.
- The production authorization function reads `process.versions.node` directly and accepts no injected version/provider/options.
- A real Node 20 executable must run the owned core lane. Metadata, a mocked version, or prose is not execution evidence.
- Rejection must happen before OpenClaw output roots, state, target files, redirects, or OpenClaw child processes are created.
- Runtime evidence remains non-transitive and does not certify domain quality or production readiness.

### Three lowest enforcement seams

1. **Scaffold publication seam:** `src/scaffold.js:19-38`. Resolve which target was selected, gate OpenClaw, then enter build-state/operation/file preflight. AgentMo-target scaffold must continue on Node 20.
2. **Final JavaScript spawn seam:** `src/runtime-execution.js:8-22`. The assertion must run inside `runRuntimeCommand` before its sole production `spawn`; early live run/replay checks additionally protect output preflight.
3. **Direct shell mutation seam:** `scripts/openclaw-live-smoke.sh:120-204`. Gate after non-mutating argument validation but before `.env` detection/value reads, `date`, `mktemp`, redirects, scaffold, `agents add`, or gateway startup.

## Shared persistability, output, and error patterns

### Complete-candidate validation before effects

Reuse `assertPersistable`/canonical serialization rather than inventing a release-output escape hatch:

```js
// src/persistability.js:113-127
export function assertPersistable(value, options = {}) {
  validatePersistable(value, options);
  return value;
}

export function serializePersistableJson(value, options = {}) {
  const { clone, limits } = validatePersistable(value, options);
  const serialized = `${JSON.stringify(clone, null, 2)}\n`;
  assertFinalText(serialized, limits.maxBytes, { rejectRawLanguage: false });
  return serialized;
}
```

### Same validated candidate for JSON/human output

`emitPersistableOutput` validates the complete candidate, validates formatted output, and only then calls the sink (`src/persistability.js:162-198`). Runtime reports and runtime errors should pass through the existing CLI adapters; do not emit partial diagnostics first.

### Stable errors without local detail

Use a fixed error message/code from the policy assertion and let `src/cli.js:827-872` convert it into the bounded five-field envelope/human form. Numeric observed Node versions are safe bounded evidence; executable paths, env values, command output, and raw error bodies are not.

### Preserve Phase 01.1 I/O closure

Any new script output, redirection, process output, filesystem lifecycle call, or serializer sink must appear in `test/helpers/io-surface-inventory.js` and be explicitly classified. Extend `test/artifact-surface-coverage.test.js`; the final scan must return zero pending/unclassified surfaces. Do not weaken the scanner or add a broad ignore for runtime files.
