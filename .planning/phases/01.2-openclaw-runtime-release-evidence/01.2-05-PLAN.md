## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-05-01 | Spoofing / Elevation | selected executable | high | mitigate | Explicit canonical path, archive-member binary digest equality, and current-process realpath equality reject self-reporting wrappers. |
| T-05-02 | Tampering | archive/checksum/command set | high | mitigate | Exact checksum-manifest entry, archive and binary SHA-256 bindings, versioned command manifest, and command-set digest. |
| T-05-03 | Repudiation | TAP batches | high | mitigate | Machine-parseable exact pass/skip/fail/total expectations and zero-match rejection; exit code is insufficient. |
| T-05-04 | Information disclosure | receipt/failure output | medium | mitigate | Closed value-blind receipt, persistability preflight, bounded errors, no paths or raw streams. |
</threat_model>
