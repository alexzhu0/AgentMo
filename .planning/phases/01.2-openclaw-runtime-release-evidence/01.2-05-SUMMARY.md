- 将 `scripts/node20-core-lane.sh` 改为六项显式输入接口；缺项、重复项、未知项、非 absolute executable 或不可执行文件均在调用 owned helper 前稳定失败，不读取 PATH、`NODE20_BIN` 或普通 `node` 作为候选。

## Decisions Made

- 不把 runtime acquisition 放入 maintained runner。调用者必须提供已批准的 archive、checksum manifest 和 canonical executable；runner 只验证和执行。
- 不使用 exit code 作为测试证据。每个 test batch 都要求唯一机器可解析 TAP summary、非零 intended matches、零 fail/cancel/todo、内部计数一致并精确等于 manifest pin。
- 不在本计划生成或宣称新的 Node 20 execution evidence。对已批准分发 fixture 的 archive/member/executable hash 检查只是 parser/provenance contract evidence；Plan 08 才运行实际所选 Node 20 并写入 release receipt。
- child test environment 只转发运行所需的普通 host/runtime keys和五个有界 lane facts；不把任意 provider 或 secret-bearing environment 传给 owned commands。
