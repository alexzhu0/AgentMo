# Phase 01.2 Plan 09: Collision-Free CLI Runtime Environment Flag Summary

**AgentMo 的 runtime environment 输入已统一为 `--runtime-env-file`，真实 Node 与直接 shebang 入口现在都能先到达应用级 runtime gate。**

## Accomplishments

- 将 CLI value-option registry、run-plan/run/replay-run parsers、value diagnostic 与 help 中的公开 spelling 全部改为 `--runtime-env-file`。
- 没有保留 AgentMo `--env-file` alias，也没有增加 wrapper、NODE_OPTIONS 生产要求或调用方 delimiter convention。
- 移除不兼容 runtime 测试 helper 在 binary 前插入的 `--`，覆盖真实 `node ./bin/agentmo.js ...` 形态。
- 新增直接执行 package shebang entrypoint 的 canary；fixture 只模拟测试进程版本，不形成 production override。
- scaffold、live run、live replay 在 missing/unreadable runtime-env、artifact/message/workspace/output canary 之前稳定返回 `AGENTMO_OPENCLAW_RUNTIME_UNSUPPORTED`，请求输出根保持不存在。
- compatible run-plan 仍只输出 `SecretPresence` metadata，不泄露 env value 或 host path。
