# Phase 01.2 Plan 11: Node 20 Trust Anchor and Consumer Separation Summary

**Node 20 evidence now requires an exact repository-owned distribution anchor, while durable receipt consumers run only after producer completion and cannot be bypassed by public marker variables.**

## Accomplishments

- Added the closed `agentmo.node20-distribution-trust.v1` policy for Node 20.20.2 darwin-arm64, pinning archive/manifest/member/executable names and SHA-256 values already observed from the approved distribution.
- Production selection keeps `--expected-version` / `--expected-arch` as exact selectors, adds current `process.platform`, and exposes no caller anchor path, environment override, download, PATH fallback, or extension point.
- Validates caller archive name, checksum-manifest digest and exact entry, archive digest, member identity/digest, selected executable digest, and canonical process identity against the anchor before owned tests execute.
- Replaced the former internally consistent fixture success with a stable `AGENTMO_NODE20_LANE_TRUST_ANCHOR_MISMATCH` self-signing rejection.
- Moved two receipt/matrix/release cases out of `test/runtime-compatibility-seams.test.js` into `test/runtime-evidence-consumers.test.js`; the Node 20 producer still runs all runtime/gate seams but cannot consume the receipt it has not yet created.
- Updated the producer core batch to exact `45/0/0/45`; total fixed manifest expectation is 88 pass, 1 skip, 0 failure, 89 total.
- Removed marker-controlled consumer returns. Missing and stale/tampered receipt child canaries remain rejected even when all historical public `AGENTMO_NODE20_*` values are supplied.

## Deviations from Plan

- **[Rule 2 - Evidence ordering] Producer/consumer circularity was removed explicitly.** A receipt producer cannot validate the final counts of the receipt it is still creating. Consumers were split into a post-publication suite, while runtime/gate seams remain in the actual Node 20 command set.
- **[Rule 1 - Intermediate verification] Full durable correspondence remains RED by design until Plan 12.** Plan 11 verifies mechanism canaries only; Plan 12 must publish the fresh receipt first and then run all five consumer cases.

**Total deviations:** 2 evidence-correctness adjustments. **Impact:** strengthens non-self-certification without reducing runtime seam coverage.
