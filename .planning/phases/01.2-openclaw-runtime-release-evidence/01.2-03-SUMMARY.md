## Decisions Made

- Kept the CLI as the sole runtime compatibility authority. Shell and documentation call the gate; neither reproduces its predicate or exposes an override.
- Used `OPENCLAW_TARGET_NODE_RANGE` as the source for generated compatibility text, preventing renderer drift from the production gate.
- Treated `runtime-check --target openclaw` as a registered zero-subject command. This preserves the exact durable digest registry and avoids falsely assigning artifact subjects to a pure process check.
- Made caller closure exact rather than advisory: new generated owners, maintained files, or unknown OpenClaw subcommands must be deliberately classified before tests pass.
- Kept declared-ready, live-success, and domain-quality evidence boundaries unchanged; the new gate proves compatibility enforcement only.
