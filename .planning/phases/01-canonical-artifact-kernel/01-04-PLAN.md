## Trust Boundaries
| Boundary | Description |
|---|---|
| CLI path → filesystem | Caller controls source/out paths and can race pathname components. |
| Planned bytes → committed output | Partial writes must never become verifiable success. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Tampering | output parent/path | critical | mitigate | Capability probe, no-follow/exclusive operations, retained handles and path-bound marker verification. |
| T-04-02 | Denial of Service | partial apply | high | mitigate | Pre-open set, fsync, receipt+marker-last validity and safe orphan reporting. |
| T-04-03 | Elevation of Privilege | cleanup | critical | mitigate | Delete only identity-proven owned filenames; never recursive-delete uncertain paths. |
| T-04-04 | Information Disclosure | receipt/errors | high | mitigate | Opaque instance token, registry basenames and value-blind formatter tests. |
</threat_model>
