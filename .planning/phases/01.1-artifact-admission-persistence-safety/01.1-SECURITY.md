## Trust Boundaries

| Boundary | Description | Data Crossing |
| --- | --- | --- |
| 外部文件 → durable admission | 一次捕获的原始 bytes 在 decode/parse/schema 前绑定外部 digest 与精确 subject | 不可信 JSON bytes、subject、digest |
| 本地 source workspace → Discover | source intake 通过 no-follow retained handle、bounded read 和 root/path identity 复核 | 潜在敏感或竞争修改的本地内容 |
| 完整候选 → filesystem/output sink | whole-candidate、serialization 和 formatted text 在首次副作用前通过 persistability | durable artifacts、报告、CLI 输出 |
| transient runtime → durable runtime evidence | message、env value、host path、raw stdout/stderr 只在瞬态执行 lane 使用 | 凭据、提示、运行输出、进程元数据 |
| 多工件 aggregate → derived evidence | aggregate 必须携带 authentic companion admissions 并从来源重算结论 | blueprint/build/run/eval/domain evidence |
| registry → generated/script/docs commands | 命令 subject 集与 exact-file digest renderer 使用生产 registry | 可复制命令、文件 operands、digest bindings |
| legacy inputs → migration publication | preview/apply 独立 retained captures；目标由 ownership marker 和 verifier 约束 | legacy bytes、迁移 payload、receipt、marker |
