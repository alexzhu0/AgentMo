# Phase 01.1 Plan 09: Exact Proposal-Only Observation Artifacts Summary

**Observation is now an exact admitted artifact derived from exact admitted run-state evidence, with safe summaries, zero durable path authority, pre-write validation, and an explicit proposal-only non-mutation boundary.**

## Accomplishments

- Registered `agentmo.observation.v1` as the exact `observation` family and closed command subjects to `observe-run -> run-state` and `observe -> observation`.
- Replaced the transitional run-state/path route with authentic admitted provenance. Observation source evidence is exactly `{identity, subject, digest}` and carries no run-state host path.
- Rebuilt observation validation around exact top-level and nested shapes, bounded ordinary metadata, exact `RedactedSummary` stdout/stderr evidence, false certification flags, and false mutation flags.
- Replaced direct filesystem writes with complete candidate/schema/persistability/serialization preflight followed by the shared atomic JSON writer.
- Added hostile prompt/transcript/tool/stdout/stderr, credential-like, host-path, extra-field, and malformed-provenance cases that prove zero output root and value-blind errors.
- Added deterministic-write and non-mutation evidence for admitted run-state plus blueprint, scaffold, runtime, and eval sentinels.
- Added fresh-process CLI bindings for both observation commands, including missing/mismatched digest zero-output behavior and exact downstream observation loading.
- Marked the observation physical sink `gated` while preserving CLI stdout/stderr as Plan 11 work.

## Decisions Made

- Required an authentic admission token in `buildRunObservation`; a valid-looking run-state object alone cannot create trusted provenance.
- Kept observation self-contained for downstream `observe`: it verifies its own exact bytes and stored parent provenance without reopening a producer path.
- Copied only bounded optional provider/model/channel/fallback metadata; oversized optional values become absent rather than making a valid parent run unusable.
- Kept regression identifiers deterministic and bounded even for extreme valid source identifiers.
- Made every mutation and certification field structurally false instead of relying on prose alone.
- Retained old pre-admission observation example bytes only as a rejection fixture; successful paths are generated from admitted run-state.
