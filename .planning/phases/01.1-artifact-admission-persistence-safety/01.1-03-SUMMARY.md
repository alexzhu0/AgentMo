## Decisions Made

- Preserved the D-13 admission order and reused the same bounded raw Buffer for digest proof, identity resolution, parsing, and validation.
- Kept ordinary document intake separate from durable admission: source reads are allowed only through the declared bounded policy and cannot return a durable AgentMo identity.
- Used the shared JSON writer for structured artifacts and the shared text writer for already-preflighted JSONL, while comparing every derived text against the complete candidate before writing.
- Kept the global secret/raw/path persistability rules unchanged. Source IDs that become secret-shaped only when embedded into colon-delimited derived identifiers receive deterministic SHA-256 aliases; ordinary `sourceId` evidence is not removed.
