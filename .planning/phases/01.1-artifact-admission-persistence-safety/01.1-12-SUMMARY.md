## Decisions Made

- Kept file expressions constrained and quoted rather than accepting arbitrary shell fragments from renderer callers.
- Used self-contained inline digest helpers for generated commands because handoff manifest commands must work when copied independently.
- Used a local helper only in the maintained script, whose invocations are parsed and checked against production subjects.
- Made explicit run-state status checks the generated/script default; production optional resolver coverage still includes status and delivery optionals plus migration ordinals.
- Moved raw OpenClaw agent-add and gateway output under the isolated state cleanup boundary rather than retaining them beside AgentMo evidence.
