## Decisions Made

- Kept the test expectation table in production: docs parsing knows only operand flags, while required/optional subject sets and ordering always come from `DURABLE_COMMAND_SUBJECTS`, `OPTIONAL_DURABLE_COMMAND_SUBJECTS`, and `subjectsForCommand()`.
- Kept the exact-byte helper inside every command block because those blocks are intended to be independently copyable; a document-global helper would make later blocks silently incomplete.
- Classified CLI message-file intake as transient runtime material and env-file intake as ephemeral secret material; neither becomes a durable artifact input.
- Kept legacy migration's retained-handle source/publication/recovery machinery explicit and narrow instead of generalizing it into canonical loaders.
- Treated release and birth reports as evidence summaries, never as transitive certification or deployment authority.
