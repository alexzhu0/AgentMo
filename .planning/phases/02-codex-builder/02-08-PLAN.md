<interfaces>
- Required host identity fields are exact hook_event_name and a bounded nonempty session_id. Raw identifiers are persisted only as digests.
- SessionStart identity binds event, session digest and normalized source; missing source is unspecified and supported explicit sources are startup, resume, clear and compact.
- Checkpoint schema adds codexDeliveryCursor with session digest, last SessionStart identity/sequence/digest, nonnegative compactionEpoch, compactState idle/pre-applied/post-applied and current Pre/Post identities/sequences/digests.
- PreCompact from idle/post-applied advances epoch; replay while pre-applied reuses identity. PostCompact requires current Pre; replay while post-applied reuses identity. A second Pre after completed Post advances epoch again.
- An optional exact challenge slot is armed only by checkpoint CAS and binds challenge digest plus one fixed host-delivery scenario. The installed bridge records only runner/release/receipt/event/before/after digests and count; no raw payload, transcript, output, path or credential. This interface is final for 02-09 consumption.
</interfaces>
