<interfaces>
- `appendImmutableJournalEntry(options)` writes one canonical entry to an absent same-directory path and returns a loader-minted admission. It requires an exact expected predecessor admission for successors and never updates a logical pointer.
- `loadImmutableJournal(options)` bounded-scans immutable entry files and accepts exactly one contiguous genesis-to-head chain. Forks, gaps, orphans, duplicate sequence values, malformed published entries, unknown published files, unsafe metadata, and unfinished publications are bounded conflicts.
- The generic primitive supplies storage and identity safety only. Checkpoint and later UAT adapters own their closed schemas and transition rules.
- `loadBuilderCheckpoint(path, { expectedDigest })` returns a private admission binding canonical bytes, digest, sequence, predecessor digest, and entry identity. Exact legacy checkpoint bytes may be admitted only as read-only genesis input; no compatibility mirror is overwritten.
- Event reducers accept a loader/publication-minted event admission or recompute the canonical event digest and require equality before replay state changes.
</interfaces>
