<interfaces>
- `retireExactLifecyclePath(...)` centralizes lifecycle retirement: retain the admitted source handle and identity, atomically move the current directory entry to a random mode-0700 private quarantine, and recognize success only when the quarantined entry is the admitted inode and digest.
- Successful retirement leaves the canonical path absent and the exact prior inode retained as inert evidence. A mismatch preserves the moved entry in quarantine, preserves any late canonical entry, and returns a bounded conflict; cleanup never unlinks a quarantine pathname.
- Receipt recovery reads the admitted prior receipt through its retained handle and publishes those exact bytes with an absent-only, no-follow exclusive destination handle, file sync, revalidation, and parent sync.
- The lifecycle result exposes bounded status, exact digest, and value-blind quarantine identity for later one-way evidence reference. It is not a mutable journal or admission decision.
</interfaces>
