## ASVS L1 Trust Boundaries

| Boundary | Description |
| --- | --- |
| npm tarball -> release loader | Packed executable bytes enter the release trust root. |
| release inventory -> project | Fixed assets become executable project files. |
| installed skill -> launcher | User-visible skill invokes receipt-owned code. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-02-05-01 | Spoofing | runtime asset identity | high | mitigate | Bind source, destination, digest and length in one sorted release basis. |
| T-02-05-02 | Tampering | import closure and project bytes | high | mitigate | Fixed allowlist, static closure check, no-follow reads, no-clobber publication and receipt-last verification. |
| T-02-05-03 | Repudiation | projection status | medium | mitigate | Report projected/declared state separately from host activation evidence. |
| T-02-05-04 | Information disclosure | packed child environment | medium | mitigate | Empty cwd, minimal environment and no raw stdout/stderr or environment persistence. |
| T-02-05-05 | Denial of service | malformed import graph | low | accept | Bounded file count/size and deterministic rejection leave zero success receipt. |
| T-02-05-06 | Elevation of privilege | global executable substitution | critical | mitigate | Skill invokes only the exact project-local Node launcher. |
| T-02-05-SC | Tampering | dependency installation | low | accept | No dependency is installed; only repository-owned packed bytes are admitted. |
</threat_model>
