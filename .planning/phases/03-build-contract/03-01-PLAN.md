## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest bytes → collector policy | Untrusted bytes must be exact-admitted and validated before a URL or bound is used. |
| approved HTTPS URL → network destination | Redirects, DNS/address resolution, status, headers, and streamed bytes are untrusted. |
| retained response bytes → derived record | Digest authority precedes decode, redaction, summary, provenance, or confidence. |
| candidate set → durable output root | A full preflight and absent-root transaction must precede any visible success artifact. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing / Information Disclosure | URL, redirect, DNS/address destination | high | mitigate | Exact HTTPS allowlist, no credentials, manual bounded redirects, public-address/socket-binding checks, hostile tests before transport success. |
| T-03-02 | Denial of Service | streamed response and deadlines | high | mitigate | Serial requests, source/aggregate deadlines, declared and actual byte limits, abort at maxBytes+1, no unbounded retry. |
| T-03-03 | Tampering | response-to-record derivation | high | mitigate | Hash exact retained bytes first; separate declared trust, evidence class, provider metadata, and confidence rationale. |
| T-03-04 | Information Disclosure | durable output and errors | high | mitigate | Existing persistability/redaction gates, no raw body/header/credential/path fields, bounded error codes only. |
| T-03-05 | Tampering / Repudiation | multi-file publication | high | mitigate | Whole-set canonical serialization and preflight before output-root creation; absent-root transaction; injected late-failure test proves zero visible set. |
| T-03-06 | Elevation of Privilege | public CLI transport selection | medium | mitigate | Production route uses the built-in closed transport; injection is module-test-only and no CLI/env/module-path override exists. |
</threat_model>
