</objective>

The only install transport is a deterministic archive. Define one closed `archiveBinding` shape containing `archiveSha256`, `manifestDigest`, `inventoryDigest`, and the complete sorted `members[]` closure. Each member contains `relativePath`, `type: "file"`, fixed `mode`, `byteLength`, and `sha256`.
The lifecycle model receives an already verified archive closure, never a package directory or manifest-only value. Plan 04-07 owns create-only writers and the prerequisite receipt descriptor; Plan 04-08 owns the no-follow archive reader, remaining authority registry entries and CLI.
The lifecycle action is exactly `install|upgrade|rollback|uninstall`. Ordinary approval, every sensitive-action decision and the whole exact conflict-set approval remain independent authorities even when displayed in one review.
</interfaces>
