## Phase Goal

**As a** developer, **I want to** deterministically generate an offline-inspectable, least-trust Agent Package from the approved build contract, **so that** I can separately authorize a safe OpenClaw installation.

<objective>
Bind and approve a canonical native-plugin byte recipe plus durable exact target/carrier admission before executable package generation.

Purpose: A verbal checkpoint cannot authorize generated code, pre-existing implementation bytes would create a circular dependency, and install approval cannot repair an upstream target-revision or hook-carrier mismatch.
Output: Phase 3-reapproved build-contract/plan-approval bytes carrying the canonical recipe, then a machine-verifiable target/carrier admission artifact and digest, or a deliberate Phase 4 pause.
</objective>
