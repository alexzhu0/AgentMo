Purpose: Give the operator a stable, value-blind review surface per D-40.
Output: Offline inspector, public artifact contract/registry entries, and `package-inspect` CLI.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Package directory/archive → inspector | Untrusted filesystem members become review evidence |
| Inspection candidate → human/JSON output | Bounded metadata crosses the output boundary |

| T-04-12 | Tampering | archive/member inventory | high | mitigate | External archive digest, retained no-follow identity, exact set equality and manifest/inventory/member closure checks per D-42. |
| T-04-13 | Information Disclosure | inspection output | high | mitigate | Shared persistability audit and hostile canaries reject secrets/raw state before formatting. |
| T-04-14 | Spoofing | manifest/inspection status | medium | mitigate | Exact external manifest digest and closed registry; inspection explicitly remains non-runtime evidence. |
| T-04-15 | Elevation of Privilege | plugin/MCP inspect | high | mitigate | Manifest-only byte inspection; no plugin import, MCP process, shell or OpenClaw CLI execution. |
