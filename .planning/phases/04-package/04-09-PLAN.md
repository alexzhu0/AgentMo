<interfaces>
`applyOpenClawInstallPlan(options)` is the only Phase 4 target mutation export. It requires explicit path plus external SHA-256 pairs for the Plan 04-02 target/carrier admission, deterministic archive, probe, `agentmo.openclaw-install-plan.v1`, `agentmo.openclaw-install-approval.v1`, every required `agentmo.openclaw-sensitive-action-decision.v1`, and the `agentmo.openclaw-conflict-approval.v1` when conflicts exist. Install additionally requires `agentmo.openclaw-absent-genesis-authority.v1`; other lifecycle actions require the exact prior receipt, and rollback also requires the selected predecessor receipt/archive.
No Plan 04-08 lifecycle authority or Plan 04-07 receipt is accepted as a parsed caller object, trusted builder return, embedded digest, same-process cache, package root or manifest-only input. Apply starts from exact published bytes and caller-supplied external digests and re-admits each under its closed artifact subject in the fresh apply process.
Before the private journal or any effect, apply no-follow retains the archive path, verifies the external archive SHA-256, then revalidates its internal manifest digest, canonical inventory digest and every member path/type/mode/length/digest against the complete archive closure repeated in the plan and every decision.
Receipt identity is `agentmo.openclaw-install-receipt.v1` with `status: complete|incomplete`; both states are mechanism-only and non-self-certifying.
The receipt records `lifecycleAction: install|upgrade|rollback|uninstall`, exact predecessor receipt digest or absent-genesis digest, immutable successor linkage and per-path base/current/desired/owner/identity observations.
Failure-recovery cleanup predicate requires all four facts: created by this attempt, exact owner marker digest, unchanged retained file identity, and current content digest equals desired digest. This is separate from the operator-requested explicit rollback lifecycle.
</interfaces>
</context>
