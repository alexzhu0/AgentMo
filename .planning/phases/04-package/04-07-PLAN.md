## Phase Goal

**As a** developer, **I want to** deterministically generate an offline-inspectable, least-trust Agent Package from the approved build contract, **so that** I can separately authorize a safe OpenClaw installation.

Purpose: Remove the receipt-schema dependency inversion while preserving D-35 through D-42 and the receipt-last transaction boundary.
Output: Authority writers plus the receipt identity/schema/validator/contract/subject/registry prerequisite.
</objective>
